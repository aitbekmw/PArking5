# Parking Occupancy Detection

Подсчёт свободных мест на парковке по видео: YOLOv8 находит машины, алгоритм проверяет, занято ли каждое размеченное место.

![demo](docs/demo.gif)

## Как это работает

1. Кадр уменьшается до 1280×720.
2. YOLOv8n детектирует транспорт (`car`, `truck`, `bus`, `motorcycle`) с порогом уверенности 0.35.
3. Для каждой из 17 парковочных зон проверяется перекрытие полигона зоны и bounding box машины:
   - если центр бокса внутри полигона — место занято;
   - иначе считается площадь пересечения маски полигона и маски бокса;
   - если пересечение больше 10% площади зоны — место занято.
4. На кадр наносится оверлей: красный — занято, зелёный — свободно, сверху счётчик `Total / Free / Occupied`.

## Данные и разметка

**Обучающего датасета нет** — модель не дообучалась. Используется предобученная `yolov8n` на COCO (классы `car`, `truck`, `bus`, `motorcycle`), порог уверенности 0.35.

Что размечено вручную — **17 парковочных зон** на эталонном кадре 1280×720. Каждая зона — полигон из 5 точек в пиксельных координатах:

```python
[(154, 154), (213, 173), (170, 296), (104, 280), (147, 156)]
```

Координаты подбирались по видео: кадр ставился на паузу, обводились углы каждого места с запасом, чтобы в зону попадала машина любого размера, но не попадали соседние.

### Как определяется занятость

Два условия, второе — на случай, если машина стоит криво и её центр вышел за пределы зоны:

1. **Центр bounding box внутри полигона** — `cv2.pointPolygonTest` ≥ 0.
2. **Пересечение масок** — полигон и бокс растрируются в маски (`cv2.fillPoly` / `cv2.rectangle`), считается площадь пересечения. Если она больше **10% площади зоны** — место считается занятым.

Порог 10% отсекает ложные срабатывания, когда машина проезжает по краю зоны или соседний автомобиль задевает бокс.

## Стек

Python · OpenCV · YOLOv8 (Ultralytics) · NumPy

## Запуск

```bash
pip install -r requirements.txt
```

Положи видео `parking2.mp4` в корень проекта (в репозиторий оно не входит — файл большой) и запусти:

```bash
python main.py
```

## Управление

| Клавиша | Действие |
|---|---|
| `s` | сохранить скриншот в `shoots/` |
| `v` | начать / остановить запись видео в `records/` |
| `q` | выход |

## Разметка мест

Координаты зон лежат в `main.py` в списке `parking_places` — это полигоны по 5 точек на кадре 1280×720.
Чтобы разметить свою парковку, поменяй координаты под своё видео. Черновик разметки есть в `parking_places`.
